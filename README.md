   * HTML5 Canvas with 360-degree tactical radar sweep, rotating coordinate rings, and dynamic IDS/AI telemetry nodes.
   * Universal zero-border-radius brutalist aesthetics.
2. **Flagship Product Showcase: Driftnet (`DriftnetShowcase.jsx` & `DriftnetSimulator.jsx`)**:
   * Complete product section spotlighting `driftnet.tech`.
   * **Live Interactive Telemetry Simulator**: Visitors can toggle traffic streams (*Normal Baseline*, *Lateral Sweep*, *Exfiltration*, *Port Sweep*), observe real-time Mahalanobis distance scores ($D_M$), and streaming packet hex buffers.
   * Direct links to `https://driftnet.tech`.
3. **Interactive 7-Stage DAG Visualizer (`AiPipelineDag.jsx`)**:
   * Production media pipeline modeled directly from Dhruv Goyal's The Economic Times generative video engine.
   * Interactive execution stages with live token throughput, latency tracking, and fallback triggers.
4. **Interactive Tactical CLI Terminal (`TacticalTerminal.jsx`)**:
   * TTY command emulator supporting `help`, `driftnet`, `founders`, `audit`, `roi`, `contact`, and `clear`.
   * Real-time output feedback with quick command execution pills.
5. **Interactive Compute ROI Calculator (`RoiCalculator.jsx`)**:
   * Real-time savings calculator modeling verified 58% inference cost reduction.
6. **Practice Matrix Bento Grid (`ServicesBento.jsx`)**:
   * Enterprise AI & Multi-Agent Systems
   * Cyber Defense & Network Anomaly Architecture
   * Distributed Data Platforms & Cloud Infrastructure
   * Enterprise Product Strategy & Commercial Operations
7. **Interactive Scoping & Consultation Modal (`ContactModal.jsx`)**:
   * Direct encrypted inquiry dispatch to founders with celebratory neon confetti.

## Local Development & Deployment

### Run in Development Mode
```bash
npm run dev
# Starts server at http://localhost:3000
```

### Build for Production
```bash
npm run build
# Compiles optimized static assets to ./dist
```

### Preview Production Build
```bash
npm run preview
# Serves ./dist locally at http://localhost:4173
```
